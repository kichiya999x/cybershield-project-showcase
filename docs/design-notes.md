# Design Notes

## Direction

The redesign preserves the existing CyberShield poster identity: institutional blue, warm off-white paper surfaces, restrained navy typography, thin rules, and editorial spacing. It avoids generic SaaS cards and treats the project as a university research showcase.

## Information architecture

The main showcase now follows this sequence:

1. Hero
2. Problem
3. Study Objectives & Scope
4. Introduction
5. Workflow
6. Cybersecurity
7. Developed System
8. Research Results
9. Methodology
10. Research Team

The separate `/research/` page is a document-style summary with verified background, objectives, scope, methodology, system and cybersecurity approaches, evaluation findings, limitations, recommendations, researchers, and adviser.

## Interface evidence

Dashboard previews remain interactive tabs with keyboard arrow, Home, and End navigation. The modal screenshot viewer supports keyboard focus and Escape dismissal. The Administrator image is now a sanitized public asset rather than a placeholder.

## Deferred enhancement

An approved, captioned system walkthrough using sanitized demonstration data remains a future enhancement. No empty or “coming soon” walkthrough block is rendered in the current showcase.
